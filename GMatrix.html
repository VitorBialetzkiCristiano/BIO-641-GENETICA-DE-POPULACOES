INTRODUÇÃO

A matriz de parentesco genômico (\(G\)), obtida segundo o Método 1 de VanRaden (2008), quantifica a similaridade genética entre indivíduos a partir de dados de marcadores moleculares do tipo SNP (Single Nucleotide Polymorphism). A construção da matriz \(G\) pode ser dividida em quatro etapas principais: obtenção da matriz de genótipos observados (\(M\)), cálculo das frequências alélicas e da matriz de valores esperados (\(P\)), centralização dos genótipos para obtenção da matriz \(Z\) e, finalmente, cálculo da matriz de parentesco genômico \(G\).

1. Matriz de genótipos observados (\(M\))

A matriz \(M\) possui dimensão \(n \times m\), em que \(n\) representa o número de indivíduos e \(m\) o número de marcadores SNP. Cada marcador é codificado de acordo com o número de cópias do alelo alternativo:

0: ausência do alelo alternativo;

1: uma cópia do alelo alternativo;

2: duas cópias do alelo alternativo.

Os dados genotípicos são inicialmente obtidos a partir do arquivo VCF e posteriormente organizados de forma que os indivíduos correspondam às linhas e os marcadores às colunas.

2. Frequência alélica e matriz P

Para cada marcador \(j\), a frequência do alelo alternativo (\(p_j\)) é calculada por:

\[ p_j = \frac{\sum_{i=1}^{n}M_{ij}}{2n}. \]

O denominador \(2n\) representa o número total de cópias alélicas observadas em uma população diploide com \(n\) indivíduos. No R, as frequências alélicas são obtidas utilizando a soma das dosagens de cada marcador:

# Frequência do alelo alternativo para cada marcador 
p <- colSums(M) / (2 * n_ind) 
# Visualizar as primeiras frequências 
head(p)
##  S1_210603  S1_210820  S1_215289  S1_561528  S1_561583  S1_689689 
## 0.23076923 0.10897436 0.05128205 0.05769231 0.49679487 0.08333333

A partir das frequências alélicas, constrói-se a matriz \(P\), que contém o número esperado de cópias do alelo alternativo para cada marcador sob o equilíbrio de Hardy-Weinberg:

\[ E(M_{ij}) = 2p_j. \]

Como esse valor esperado é o mesmo para todos os indivíduos em um determinado marcador, o vetor \(2p_j\) é replicado para todas as \(n\) linhas:

# Matriz de valores esperados
P <- matrix( 2 * p, nrow = nrow(M), ncol = ncol(M), byrow = TRUE ) 
# Verificar a dimensão 
dim(P)
## [1]   312 68979

Portanto, \(P\) possui a mesma dimensão de \(M\).

3. Matriz de genótipos Z

A matriz de genótipos centralizados é obtida pela diferença entre os genótipos observados e seus respectivos valores esperados:

\[ Z = M - P. \]

Essa transformação centraliza os genótipos em relação à média populacional de cada marcador. Dessa forma, os efeitos dos marcadores são expressos como desvios em relação à frequência alélica observada na população.

No R:

# Centralizar os genótipos 
Z <- M - P

4. Construção da matriz de parentesco genômico G

Segundo o Método 1 de VanRaden (2008), a matriz de parentesco genômico é calculada por:

\[ G = \frac{ZZ^T} {2\sum_{j=1}^{m}p_j(1-p_j)}. \]

O numerador,

\[ ZZ^T, \]

produz uma matriz \(n \times n\) que representa a covariância entre os perfis genômicos dos indivíduos. O denominador,

\[ 2\sum_{j=1}^{m}p_j(1-p_j), \]

é um fator de escala baseado na heterozigosidade esperada dos marcadores. Essa padronização permite que a matriz \(G\) seja expressa em uma escala na qual a variância genética média da população é aproximadamente igual a 1.

No R, o cálculo é realizado em duas etapas:

# Numerador
Numerador <- Z %*% t(Z)
# Denominador 
Denominador <- 2 * sum(p * (1 - p)) 
#Matriz G
G <- Numerador / Denominador

A matriz resultante possui dimensão \(n \times n\), pois representa as relações genômicas entre todos os pares de indivíduos.

5. Visualização da matriz G

A estrutura da matriz de parentesco genômico pode ser visualizada por meio de um mapa de calor (heatmap):

heatmap(G)

No mapa de calor, cada elemento \(G_{ik}\) representa a relação genômica entre os indivíduos \(i\) e \(k\). Valores relativamente maiores indicam maior similaridade genômica, enquanto valores menores indicam menor similaridade. A diagonal principal contém os valores de relacionamento de cada indivíduo consigo mesmo, enquanto os elementos fora da diagonal representam as relações genômicas entre indivíduos distintos.
